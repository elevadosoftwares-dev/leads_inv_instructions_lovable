- Stack: TanStack Start (React + Node server functions) with SQL Server via `mssql`. Server-only code lives in `src/server/*.server.ts` and is loaded with `await import(...)` inside server functions (the build fails if browser code imports `src/server/`); schema changes go in `database/schema.sql` and must stay idempotent (`IF OBJECT_ID(...) IS NULL`).
- All database access goes through server functions in `src/lib/*.functions.ts` (inv, users, auth).
- Roles are `dbo.users.role` (`admin` | `user`); the first sign-up becomes admin, later sign-ups are plain users. Reads use `requireAuth`, writes `requireAdmin` — the server, not the UI, enforces view vs edit rights.
- No e-mail: admins reset passwords from Users; signed-in users change their own at /reset-password.
- Clients and PICs referenced by an instruction cannot be deleted (foreign keys without ON DELETE); the UI suggests setting them inactive.
